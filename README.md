Meetup Event Management App 🎉

A responsive Meetup Event web application where users can explore different events, filter them, search by title/tags, and view complete event details.

🚀 Live Demo
https://meetup-65y4.vercel.app/

📌 Features
🔍 Search events by title and tags
🎯 Filter events (Online / Offline)
📄 Detailed event information page
👥 Speaker/Host information section
📱 Responsive UI design
⚡  React using

🛠️ Tech Stack
React.js
React Router
Bootstrap / CSS
JavaScript
Vercel (Deployment)

⚙️ Installation & Setup
# Clone the repository
git clone <your-github-repo-link>

# Move into project folder
cd meetup-app

# Install dependencies
npm install

# Start development server
npm run dev
